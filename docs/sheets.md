# Synthetic Spreadsheets (`data/sheets/`)

FormulaLM uses 25 fully synthetic spreadsheets generated by [`src/data/sheets.py`](../src/data/sheets.py) with a fixed seed (`seed = 42`). Every sheet is saved in both CSV and XLSX format in `data/sheets/` alongside `data/sheets/manifest.json`.

No real people, organizations, cities, addresses or personal data are used anywhere. All person names (e.g., `Kaelen Vorn`), organizations (e.g., `Vektor Supply`), cities (e.g., `Ashvale`), product names and numeric values are randomly sampled from invented vocabularies.

## Regenerating the sheets

```powershell
# Windows PowerShell
.\scripts\tasks.ps1 sheets
```

```bash
# Linux / macOS / Git Bash
make sheets
# Or directly:
uv run python -m src.data.sheets --seed 42 --out-dir data/sheets
```

Generation is deterministic for a fixed seed: CSV files have identical SHA-256 hashes across runs, and XLSX metadata timestamps are pinned to `2026-11-24T00:00:00`.

## Schema and data conventions

- **Dimensions:** 5 to 8 columns (`A`–`H`) and 30 to 200 rows per sheet.
- **Column types:** `text`, `integer`, `decimal`, `date`, `category`.
  - Dates are stored as ISO `YYYY-MM-DD` in CSV and native Excel `date` cells (`yyyy-mm-dd`) in XLSX.
  - Decimals are rounded to 2 decimal places (`0.00` format in XLSX).
- **Headers:** mix single-word headers (`Region`, `SKU`, `Status`, `Clicks`) and multi-word headers with spaces (`Unit Price`, `Order Date`, `Hire Date`, `Final Score`).
- **Key column:** column `A` is always a unique, non-null identifier (e.g., `SL-1001`, `ORD-1001`) so lookup formulas (`VLOOKUP`, `XLOOKUP`, `INDEX`/`MATCH`) have clean, unambiguous targets.
- **Blank cells:** ~4% of cells (at least 2 per sheet) in one designated non-key nullable column are left empty (`""` in CSV, `None` in XLSX) to exercise blank handling in `COUNT`, `COUNTIF`, `AVERAGE`, and `IFERROR`.
- **Worksheet name:** every XLSX workbook uses a single sheet named `Sheet1`, with headers on row 1 and data starting on row 2.

## Manifest format (`data/sheets/manifest.json`)

The manifest is the single index read by downstream formula generation and evaluation scripts. Top-level fields:

- `seed`: RNG seed used for both row generation and split assignment (`42`).
- `num_sheets`, `train_sheets`, `test_sheets`, `heldout_fraction`: split summary (`25`, `20`, `5`, `0.2`).
- `row_range`, `blank_rate`, `domains`: generator parameters and sorted domain list.
- `train_sheet_ids`, `test_sheet_ids`: disjoint lists of sheet IDs. The 5 test sheets are held out exclusively for unseen-schema evaluation and must never be used during training or validation data generation.
- `sheets`: per-sheet metadata list, each containing:
  - `sheet_id`, `domain`, `split`, `description`, `num_rows`, `num_cols`, `blank_cells`, `key_column`
  - `csv_path`, `xlsx_path`, `csv_sha256`
  - `columns`: ordered list with `letter`, `name`, `type`, `nullable`, `unique`, `null_count`, `sample_values`, plus `categories` (for `category` columns) or `min`/`max` (for numeric and `date` columns).
